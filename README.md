# 🌍 GetOut

**AI-powered outdoor adventures for curious kids**

Less scrolling, more exploring. Your real adventure starts outside!

## About

GetOut encourages children to spend less time on screens and explore the real world through fun, AI-generated daily quests.

## Features

- 🌱 Daily outdoor learning quests
- 🔭 Nature, astronomy, science, exploration, and creativity activities
- 🤖 AI-generated quests and mentor feedback using Ollama
- 💎 Gems and daily streaks to encourage consistency
- 🏅 Badges and quest history to track progress

## Built With

- Python
- Streamlit
- Ollama
- Qwen 2.5 (1.5B)

## Run Locally

1. Install Python and Ollama.
2. Download the model:

   `ollama run qwen2.5:1.5b`

3. Install the required Python packages:

   `pip install streamlit ollama`

4. Run the app:

   `python -m streamlit run app.py`

## Project Goal

GetOut helps kids replace passive screen time with curiosity, outdoor discovery, and real-world learning.
